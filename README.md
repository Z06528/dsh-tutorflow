# TutorFlow 通用教学增强

TutorFlow 是 DeepSeek Harness（DSH）的教学增强插件。

它**不是**一本教材，也**不是**一段很长的系统提示词。它给宿主里已经配置好的模型补上一套「会教书」的方法：
先判断你只是要一个答案、还是想真正弄懂；再决定从哪里切入；一次只讲一个点、只问一个问题；
你答错时先分清错在哪一类，再换一种讲法；答对一次也不算过，要换个条件再确认；
最后把你的掌握程度、错误类型和下次复习时间记在本机。

**不限学科。** 概率论只是它自带的一个示例课程。矩阵特征值、中心极限定理、飞机升力、
Python 装饰器、机会成本、天空为什么蓝、人为什么要睡觉——这些都没有预设课程，插件照样能教。
因为被固化下来的是教学动作的形状，不是知识点本身。

它不另接模型，不把对话转发出去，不加载任何境外 CDN。

## 它解决什么问题

大多数模型会答题，但不太会教：一上来就给完整解答、一口气讲完一整章、
学生说「不懂」就换个更抽象的说法再讲一遍、答对一次就认为掌握了。

TutorFlow 把这几件事变成机械约束：

| 常见问题 | 插件怎么做 |
| --- | --- |
| 直接倒答案 | 先定位，再拆步；一次只给一步，且不给完整解答 |
| 一口气讲完 | 路线最多 8 步，当前只做一步；`advance` 不为真就不许往下 |
| 答错只说「不对」 | 先分型：概念 / 步骤 / 计算 / 审题 / 记忆 / 表达，再按类型换补法 |
| 换个说法再讲一遍 | 表征轮换：直观 → 类比 → 图形 → 推导 → 反例，同一种不许连用两次 |
| 答对就算会 | 要两次证据才推进；跨天到场过、且复习过一次，才记为「已掌握」 |
| 把简单问题变成课堂 | 只要事实或结论时直接给，最多三句，再问一句要不要展开 |

## 能做什么

- **需求识别**：区分「要快速答案」与「想系统学」；识别概念 / 原理 / 步骤 / 代码 / 数学 / 数据 / 开放式问题 / 事实 / 技能。
- **自主路线**：按知识类型生成 3–4 步骨架；模型也可以自己提交 3–8 步路线（`tutorflow_plan`），插件只校验形状：步数、概念不重复、每题只问一个问句。
- **一次一问**：工具返回的指令里永远只有一个「必须只问这一个问题」。
- **错误分型**：六种错误类型，各自的补法不同——算错不重讲概念，记不住不给推导。
- **掌握判定**：证据条数、置信度、跨天、复习排期。一次答对置信度约 0.2，不会变成「已掌握」。
- **本地图形**：函数、正态密度与分布函数、积分区域、坐标、知识结构、流程图、离散连续对照、柱状对比、多曲线、表格、结构树、时间线、代码执行追踪。全部本地 SVG。
- **模型能力分档**：`small / standard / strong`。小模型档下插件承担对错判定与路线，指令里会直接写明「照这一条做即可」。
- **无工具也能教**：系统提示段本身就是一套完整教学法，模型一次工具都不调也能按它教。

## 环境

- DSH `>=0.2.0 <0.3.0`（含 `0.2.2-rc.3` 这类预发布版本）
- Node.js 22.19+。DSH 0.2.2 命令行本身要求 Node 24+
- 不需要 OpenAI、Google 或任何额外付费 API
- 不联网、不收集对话、不上传任何数据

## 安装

已发布到 npm（latest 为 **0.2.1**）：

```sh
dsh plugin --profile web add dsh-tutorflow
```

包页面：<https://www.npmjs.com/package/dsh-tutorflow>。
同一个包名下还有一个 `0.0.0-stage`，那是发布流程用的占位包，**不要拿它当安装版本**。

想装本地改动或只有源码时，用目录：

```sh
dsh plugin --profile web add /path/to/dsh-tutorflow
```

从 GitHub 直接装需要本机能调用 `git` 并访问 github.com；不满足就用上面的 npm 或本地目录。

桌面版不要对 `desktop` 这个 profile 名使用命令行安装，改在应用里的**插件**页面安装。
装完后重启这个 profile。详细步骤见 [INSTALL.md](INSTALL.md)。

## 卸载

```sh
dsh plugin --profile web remove dsh-tutorflow
```

这会去掉依赖和 bundle 层。学习记录还在 `$DSH_HOME/dsh-tutorflow/`。
要连记录一起删，退出 DSH 后删除该目录，或在对话里说「清除学习记录」。

## 怎么用

在对话里正常提问就行，不需要记命令：

- 「我不理解概率密度函数。」（有预设课程，走准备过的五步课）
- 「什么是矩阵的特征值？」（无预设课程，走通用概念路线）
- 「为什么飞机能够飞起来？」（走原理路线：固定现象 → 因果链 → 条件 → 反事实）
- 「Python 装饰器是什么？」（走代码路线，会给能跑的最小例子和逐行追踪）
- 「快速说一下机会成本是啥，别展开。」（走快速通道，不变成课堂）
- 「换成查漏补缺。」「给我一个轻提示。」「画一张标准正态曲线，并把 −1 到 1 涂上。」
- 「查看学习进度。」「开始复习。」「导出学习记录。」

## 工具

| 工具 | 作用 |
| --- | --- |
| `tutorflow_start` | 判断这是要答案还是要上课、属于哪类知识，给出这条路线的第一个动作 |
| `tutorflow_plan` | 提交你自己拟的教学路线（3–8 步），覆盖通用骨架 |
| `tutorflow_answer` | 分析学生回答，给出下一个教学动作 |
| `tutorflow_hint` | `light` / `idea` / `formula` / `solution` 四级提示 |
| `tutorflow_plot` | 14 种本地 SVG 图型 |
| `tutorflow_mode` | 切换课堂姿态：系统学习 / 解题带练 / 查漏补缺 / 快速解释 / 自主探索 |
| `tutorflow_progress` | 查看、导出、清除、复习，以及设置模型能力档 |

工具参数向后兼容：0.1.0 的调用方式仍然可用（`judgement` 与 `verdict` 等价，「答错」对外仍写作 `wrong`）。

## 数据与隐私

- 学习记录写在 `$DSH_HOME/dsh-tutorflow/state.json`（可用 `TUTORFLOW_HOME` 改目录），原子写入。
- 记录内容：学过哪些知识点、掌握分与置信度、错误类型分布、错题原话片段、下次复习时间、当前路线游标。
- 不记录对话全文，不上传，不发给第三方。
- 卸载插件不会删记录；删除该目录或在对话里说「清除学习记录」即可清空。

## 更新日志

### 0.2.1 — 与 npm 上的版本号对齐

内容与 0.2.0 完全相同：同一份源码、同一个提交、`fileCount` 与 `unpackedSize` 都一样，
只是把 npm 上的 latest 对齐到 0.2.1。安装用 `dsh plugin --profile web add dsh-tutorflow`。

### 0.2.0 — 从「概率论教学插件」改为「通用教学增强」

这一版把教学能力与课程内容彻底拆开。原来换成任何非概率论知识点，就只能退化成普通问答；现在不会了。

**新增**

- 分类层 `lib/taxonomy.js`：意图 6 类、知识类型 10 类、学科 18 类、复杂度 1–5、起点 4 档。两条纠偏规则：
  「什么是矩阵的特征值」不算数学题，走概念路线；含「定理 / 为什么 / 机制」且不是题，走原理路线。
- 路线层 `lib/plan.js`：按知识类型生成通用骨架；模型可用 `tutorflow_plan` 提交 3–8 步自拟路线，
  插件只校验形状（步数、概念不重复、每题一个问句）。
- 动作层 `lib/moves.js`：表征轮换、六类错误分型与各自补法、按学科优先级轮换的追问框架、五种课堂姿态。
- 记忆层 `lib/mastery.js`：证据累积、置信度、六档掌握状态、简化 SM-2 间隔复习。
- 新工具 `tutorflow_plan`；其余六个工具参数扩展，**旧调用方式保持可用**。
- 图形从 8 种扩到 14 种：新增柱状对比、多曲线对照、表格、结构树、时间线、代码执行追踪。
- 客户端「教学」面板改为通用本地绘图台：可输入任意表达式画图，保留正态分布浮层。
- 图标 `icon.svg`、中英文 locale、`meta.detail` 之外的插件市场元数据。
- 状态文件 v1 → v2 自动迁移，旧掌握度与错题不丢。
- 测试从 8 项扩到 36 项，覆盖跨学科无课程包场景、错误分型、证据阈值、路线校验、通用图型、schema 子集。

**修复**

- 判对错不再靠关键词命中。0.1.0 里课程包外的知识点没有 `signals`，学生永远只能拿到 `partial`。
- 模型给的判定不再被引擎覆盖；只有在课程包命中误解句式时才覆盖，且给出具体误解名。
- 模型不给判定时**绝不默认答对**：只做「不知道→unclear」「带问号→unclear」「其余→partial」的保守推断。
- 修掉内部脚手架术语泄漏：路线里的步骤标签（如「把机制拆成因果链」）不再出现在学生可见的话术里。
- 修掉重复追问：同一类错误的追问会轮换，不再连续问同一个问题。
- 修掉「学生说没学过，却继续问他懂什么」：改为直接给一个可观察的场景，只问一个看场景就能答的问题。
- 修掉模式覆盖自主性：姿态只调课堂气氛与长度，不再限制模型怎么讲。

**已知限制**

- 对错判定依赖模型给出 `verdict`；模型不给时只会退化为继续追问，教学节奏会变慢。
- 间隔复习只在 `tutorflow_progress({action:'review'})` 时触发，没有后台定时器。
- 中文优先。英文 locale 只覆盖插件展示元数据，教学话术走模型自身语言。
- `market/index.json` 是自建索引，需要自己添加索引源；正式安装来源是 npm 上的包，不是这个索引。
